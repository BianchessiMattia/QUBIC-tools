# QUBIC-tools

A collection of tools and scripts developed during my work as a system engineer on the [QUBIC](https://qubic.in2p3.fr/) experiment.

## Requirements

The scripts run in the same Python environment used for qubicpack and the qubic software (qubicsoft). Set that environment up first by following the installation instructions of those packages.
